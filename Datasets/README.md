# Datasets

This folder contains the evaluation datasets used in our experiments with the proposed **GAttention mechanism**.  
Each dataset is stored in an individual subfolder:

- `ami 2018/`
- `hasoc 2019/`
- `semeval 2019 task 6/`

## Structure

Inside each dataset folder, there are two `.tsv` files:

- `train.tsv` → training set  
- `test.tsv` → validation set  

Each `.tsv` file contains three columns:

- **text** → the text of the instance  
- **task_1** → label for Subtask A  
- **task_2** → label for Subtask B
